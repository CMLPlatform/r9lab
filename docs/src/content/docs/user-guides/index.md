Guides for collecting records, setting up capture tools, and using the API from scripts and
notebooks.

If you are new, read them in sidebar order. [Getting started](getting-started/) covers account
creation. Then follow the four task guides: [Add your first product](first-product/),
[Add components](components/), [Record materials](materials/) and
[Take and upload photos](photos/). The [Data collection checklist](data-collection/) covers notes,
measurements and a final check. The [Glossary](glossary/) defines the terms.

[Hardware](hardware/) and the Raspberry Pi camera ([r9cam](r9cam/)) are optional: a phone camera is enough to
contribute. [API interaction](api/) covers reading and writing R9lab data from scripts, notebooks,
or integrations, and assumes you have an account. [Managing users](admin/) is for administrators.

For how the platform is built, see [Architecture](/architecture/).
